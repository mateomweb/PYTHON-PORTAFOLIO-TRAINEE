# Portafolio Python Trainee 🐍

Hola, soy **Mateo** 👋, estudiante y trainee de Python. En este repositorio reúno los ejercicios de práctica que voy haciendo mientras aprendo: desde lo básico hasta mis primeros pasos con POO, archivos, JSON y excepciones.

## 🗂️ Estructura

### 01 - Fundamentos
Variables, condicionales, bucles `for` / `while` y entrada de datos.

| Proyecto | Descripción |
|---|---|
| [adivina-el-numero.py](01-fundamentos/adivina-el-numero.py) | Juego para adivinar un número secreto con pistas de mayor/menor. |
| [calculadora-notas.py](01-fundamentos/calculadora-notas.py) | Calcula el promedio de 3 notas e indica si el alumno aprueba. |
| [analizador-numeros.py](01-fundamentos/analizador-numeros.py) | Cuenta positivos, negativos y ceros, y suma los números ingresados. |
| [simulador-cajero.py](01-fundamentos/simulador-cajero.py) | Cajero automático que valida retiros contra el saldo disponible. |

## ▶️ Cómo ejecutar

Requiere Python 3.10 o superior.

```bash
git clone https://github.com/mateomweb/PYTHON-PORTAFOLIO-TRAINEE.git
cd PYTHON-PORTAFOLIO-TRAINEE
python 01-fundamentos/adivina-el-numero.py
```
